# shredintel

GSB Analytics 2.0 — React component library for the GetSkiBots admin Analytics page.

Built to hand off to Botscrew for integration into the existing chatbot platform dashboard.

See [HANDOFF.md](./HANDOFF.md) for integration notes.

## Quick start

```bash
npm install
npm run dev          # local Vite preview
npm run storybook    # component gallery
```
